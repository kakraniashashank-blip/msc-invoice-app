# Automated Invoicing & AI Data Extraction System

An end-to-end Python application designed to streamline accounts receivable workflows and eliminate manual data entry. By leveraging Google Gemini LLMs for unstructured data extraction and `fpdf2` for programmatic PDF generation, this tool automatically processes billing data and produces perfectly formatted, tax-compliant invoices.

## Key Features
- **AI-Powered Data Extraction:** Integrates with Gemini AI to parse raw billing details and unstructured text into structured, standardized formats.
- **Automated PDF Generation:** Programmatically generates pixel-perfect PDF invoices, ensuring strict compliance and zero manual formatting errors.
- **Cloud Deployment:** Fully hosted on Streamlit Community Cloud for accessible, web-based invoice management.
- **Workflow Optimization:** Built to solve real-world operational bottlenecks, significantly reducing manual processing time and mitigating human error in financial operations.
